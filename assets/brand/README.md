# MARUMIE ブランド素材

| ファイル | 中身 |
|---|---|
| `marumie-wordmark-ink.svg` | ワードマーク（文字 #1A1A1A、赤い丸 #D74343）。明るい背景に使う |
| `marumie-wordmark-paper.svg` | ワードマーク（文字 #F8F6EF、赤い丸 #D74343）。暗い背景に使う |

- 雑誌の表紙（T4）の題字に使う（`eval/cover.py`）。人物の頭の後ろに重ね、赤い丸はそのまま残す
- Illustrator などで再現するとき: Bodoni Moda の可変フォントで、オプティカルサイズ（opsz）を 96 にすると同じ形になる。
  オプティカルサイズを指定できない場合は「Bodoni Moda 96pt Regular」の静的フォントを使う（隊長より、2026-11-16）
