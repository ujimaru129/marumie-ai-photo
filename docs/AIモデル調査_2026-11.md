# MARUMIE AI PHOTO：Gemini（Nano Banana）でいけるかの調査（2026-11-04）

結論: **品質・費用・速さの公開データでは、Gemini の画像モデル（Nano Banana 2.1）が第一候補で良い。**
ただし **Google の規約で「18歳未満が使う可能性が高いアプリには使えない」** という大きな制約がある。
対象年齢をどうするかを先に決め、そのうえで自前の検証（自撮り10枚）で確かめる。

> 数字の出どころは末尾の「出典」。Google の価格と規約は公式ページを直接確認した（2026-11-04）。
> 順位表（Arena）は直接読めなかったため、まとめサイトの数字。モデルは数か月ごとに変わるので、採用前にもう一度確認する。

## 1. 本人らしさ（顔が別人にならないか）

**いちばん参考になる研究**: アリゾナ州立大学ほか「A Large-scale Evaluation of Text-guided Models for Facial Editing」
（ACM Multimedia 2026 採択、2026年8月）。有名人の顔写真データ2種（CelebA・CelebSET）で、約100万枚を編集して比べたもの。

- 測り方: 顔認識の類似度が、元の写真からどれだけ下がったか（Drop_FSS、**低いほど本人のまま**）。4回続けて編集した平均
- 編集の種類: 髪型・髪色、帽子・メガネ、顔の向き

| モデル | CelebA | CelebSET | 指示どおりに編集できた度合い（CelebA、高いほど良い） |
|---|---|---|---|
| **Nano Banana（Gemini 2.5 Flash Image）** | 29.93% | **22.25%（最良）** | **79.6（最良）** |
| FLUX.1 Kontext Pro | **28.68%（最良）** | 26.21% | — |
| SeedEdit 3.0（ByteDance） | （未評価） | 28.15% | CelebSET で 77（Nano Banana と同点で最良） |
| Bagel-Edit | 30.33% | 30.81% | — |
| Qwen-Edit | 32.73% | 44.82% | — |
| FLUX.1 Dev | 89.41% | 83.69% | 最下位 |

- 著者の結論: 「顔の編集では Nano Banana が最良、FLUX Dev が最悪」。余計なところまで変えてしまう率も、Nano Banana が最も低い（CelebA で 13.8）
- 顔の向きを変える編集では、どのモデルも本人らしさが落ちやすい。髪の編集では保たれやすい
- ほとんどのモデルで、年配の顔は本人らしさが落ちやすい
- **注意（このまま当てはめられない点）**
  - 評価されたのは**旧版の Nano Banana（2.5）**。今の推奨の 2.1 は評価されていない
  - 編集の種類が「髪・小物・顔の向き」で、MARUMIE で使う「光・カメラの雰囲気・場面を変える」とは違う
  - 有名人のデータで、**日本人・アジア人の顔での結果は分けて示されていない**
  - 4回続けて編集した平均。MARUMIE は1回の編集なので、もっと保たれるはず

**人の好みの投票（Arena の画像編集ランキング）**: 2026年9月時点のまとめサイトでは、1位は OpenAI の GPT Image 系（スコア 1,526）、
Nano Banana Pro は 1,390 で7〜9位前後。サイトによって順位が食い違うため、参考程度。
「見た目の好み」では OpenAI が強く、「本人のまま」では Gemini と FLUX Kontext が強い、という傾向。

## 4. 規約・運用上の注意（ここが一番大事）

1. **年齢制限（Gemini API、公式規約）**
   「18歳以上でなければ API を使えない。また、18歳未満を対象にした、または18歳未満が使う可能性が高い
   アプリ・サービスで使ってはいけない」。Google Cloud（Vertex AI）経由でも、同じ趣旨の条項がある。
   - Boothie の売上サイトの紹介では、利用者層が「16〜40歳の女性」となっている。MARUMIE の想定の利用者にも10代が含まれやすい
   - Gemini を使うなら、**MARUMIE AI PHOTO は18歳以上向けにする**必要がある（起動時の年齢確認、利用規約への明記、
     ストアの対象年齢の設定）。10代を取りこぼすので、売上への影響がある
   - 比較: OpenAI は「18歳未満に提供する場合は追加の安全対策をとること」という条件付きで認めている（禁止ではない）。
     FLUX（Black Forest Labs）・Seedream（BytePlus）の年齢の条件は今回の調査では確認できなかった → 検証の前に規約を読む
2. **顔の写真で「禁止コンテンツ」と誤判定されることがある**
   開発者フォーラムに、普通の顔写真の編集が `PROHIBITED_CONTENT` で止められる報告が複数ある。この判定は開発者側で
   緩められない。公式の拒否率は公開されていない → **自前の検証で「止められた割合」を必ず測る**
3. **有料利用ならデータは学習に使われない**（公式規約）。不正利用の監視のために一定期間だけ記録される。
   EU・英国・スイスの利用者に出すアプリは有料利用が必須（MARUMIE は有料利用なので問題なし）
4. **モデルの入れ替わりが速い**: 2.5 → 2 → 2.1 と1年あまりで3世代。旧版は停止日が決まる。
   → 設計書どおり、モデルはサーバー側で切り替えられるようにしておく
5. 生成した画像には Google の見えない透かし（SynthID）が入る。EU の「AI で作ったことを示す」義務には好都合

## 7. 10代も対象にする場合（検討したが不採用。2026-11-04 に「AI アプリは18歳以上・Gemini が本命」に決定。記録として残す）

各社の規約を原文で確認した結果（2026-11-04）:

| 提供元 | 10代の自撮りを送れるか | 根拠 |
|---|---|---|
| Google（Gemini API / Vertex AI） | **不可** | 「18歳未満が使う可能性が高いアプリで使ってはいけない」 |
| Black Forest Labs（FLUX API） | **不可** | 開発者規約「18歳未満の人に関する画像・動画・個人データを FLUX にアップロードしてはいけない」 |
| fal.ai（FLUX・Seedream などの中継） | **不可** | 「エンドユーザーが18歳以上であることを確保する責任がある」 |
| Replicate（中継） | 不可に近い | 18歳以上が前提。18歳未満のエンドユーザーは「親として同意し責任を負う」形で、アプリには向かない。FLUX は BFL の規約も適用される |
| BytePlus（Seedream 直接） | **未確認** | 公開ページでは確認できず（お試し画面の規約は成人のみ）。営業窓口に確認が必要 |

| 自社で動かす公開モデル（例: Qwen-Image-Edit、Apache 2.0） | 可（提供元の年齢制限なし） | ただし公開研究では本人らしさが弱め（CelebSET で 44.82%、女性の顔で落ちやすい）。GPU サーバーの運用が必要 |

**→ 10代も対象にするなら本命は OpenAI（GPT Image）だった。予備は「BytePlus に確認が取れたら Seedream」「自社運用の公開モデル」。**

**OpenAI を10代向けに使うときに必要なこと（OpenAI「Under-18 API Guidance」より）**
- 年齢に合った説明（AI で加工すること、使い方）
- 年齢に合った内容の絞り込み（入力・出力の安全チェック）
- 監視と報告の仕組み（「問題を報告」ボタン、危ない例の対応手順）
- 必要に応じた年齢確認
- 最新の主力モデルを使う
- OpenAI は守られているかを監査でき、守らないと利用停止もありうる

**MARUMIE AI PHOTO での具体策**
- 対象は **13歳以上**。13歳未満は使えないと明記し、起動時に生年（年齢）を聞く
- EU では国ごとに「子どもが自分で同意できる年齢」（13〜16歳）が違う → その年齢未満は OpenAI の ZDR（申請制）を使うか、
  地域ごとに対象年齢を上げる。OpenAI に ZDR を申請しておくのが確実
- 利用者が自由に文章で指示できる形にしない（スタイルを選ぶだけ）→ 不適切な生成を起こしにくい
- **18歳未満には出さないスタイルを決める**（例: バー・寝室・水着など）。サーバーのスタイル一覧に「18歳以上のみ」の印を持たせる
- 入力と出力を OpenAI の安全チェック（moderation）にかける
- 未成年に見える顔の写真の編集を、モデル側が断る場合がある（2025年の報道。今の版は未確認）→ 検証で「若く見える顔」での止められた割合を必ず測る
  （検証の写真は成人の協力者で行う。未成年の写真は使わない）

**費用の見直し（OpenAI はやや高い）**
- 価格は第三者の計算: 1024px の出力が 品質「中」で約$0.053、「高」で約$0.211、「低」で約$0.006。編集は入力の写真の分（1枚 $0.01〜0.02 程度）が加わる
- → 品質「中」で **1回 約$0.07（約10〜11円）**。Gemini（約5円）の約2倍
- 設計書 5.3 の採算は「1回 約6円」で計算していた → **1日の上限を下げるか、価格を上げる**必要がある（設計書を更新済み）
- 公式の価格ページはこの環境から読めなかったので、契約前に確認する

## 8. Boothie は何を使い、年齢をどうしているか（公式の規約・プライバシーポリシー、2026-11-04 確認）

- **AI は Google の Gemini**。「AI Photobooth では、選んだ写真を Google の生成 AI（Gemini）に送る」「Firebase のサーバーが Google の AI に転送する」と明記
- **2つのモード**: Classic Photobooth（端末内のフィルター、AI なし、写真は送らない）と AI Photobooth（Gemini で生成）
- 写真・指示・結果はサーバーに残さない。作った履歴は端末だけに保存。アカウント不要。課金は RevenueCat
- **対象年齢: 米国13歳以上、EU・英国16歳以上**（利用規約の Eligibility）。どちらも2026年7月23日更新
- 一方、Google の規約（Gemini API の追加規約、Google Cloud の生成 AI の規約。Firebase AI Logic は後者に従う）は
  「18歳未満が使う可能性が高いアプリで使ってはいけない」。**Boothie の対象年齢は、Google の規約の文面とは合っていないように見える**
  （Google と個別に合意している可能性もあるが、公開情報からは分からない）
- 規約違反と判断されると、API の停止＝AI 機能が全部止まる可能性がある。売却の手続きで確認される点にもなる
- → MARUMIE は、Boothie の作りは参考にしつつ、年齢の扱いは真似しない

## 9. Stability AI（platform.stability.ai）（2026-11-04 確認）

- **会社の重心が音声に移っている**: API のトップページは Stable Audio が中心。画像は Stable Diffusion 3.5 系
- **「文章で指示して、顔はそのまま編集する」型のモデルが無い**（Nano Banana・FLUX Kontext・GPT Image のような指示型の編集）。
  画像の編集は次の個別の機能の組み合わせ:

| 機能 | 内容 | 1回（1クレジット=$0.01） |
|---|---|---|
| Replace Background & Relight | 人物はそのまま、背景の差し替えと光の当て直し | 8クレジット（$0.08、約12円） |
| Style Transfer | 参考画像の雰囲気を写す | 8（$0.08） |
| Structure / Style Guide | 入力画像の形や雰囲気を手がかりに新しく生成 | 5（$0.05） |
| Search and Replace / Inpaint | 指定した物を置き換える・塗り直す | 5（$0.05） |

- 本人らしさの公開データは見つからなかった（facial editing の研究にも、Arena の画像編集ランキングの上位にも入っていない）。
  Style Transfer・Structure は「新しく描き直す」仕組みなので、顔が別人になりやすいと考えられる（要検証）
- 費用は Gemini（約5円）の1.5〜2.5倍
- 規約: 画像のサービスは利用者（アカウントの持ち主）が18歳以上。エンドユーザーは自社アプリ経由で使ってよい。
  Google のような「18歳未満が使うアプリでは使えない」という条項は見当たらない（MARUMIE AI PHOTO は18歳以上なのでどちらでも問題ない）
- **判断: 本命にはしない。** 使うとしたら「背景すっきり」「スタジオ照明」のような、人物を残して背景と光だけ変えるスタイル向け
  （Replace Background & Relight）。検証で Gemini と比べ、勝てばそのスタイルだけ Stability にする（スタイルごとにモデルを選べる作りなのでできる）

## 10. DeepAI（deepai.org）（2026-11-04 確認）

- 一般の人向けの AI ツール集（チャット・画像生成・写真編集・動画・音楽など）。開発者向けの API もある
- 写真編集は「Standard / Genius / Super Genius」から選ぶ形で、**中身がどの会社のモデルかは公開されていない**
- 費用（DeepAI Pro の追加分）: HD 1枚 1¢、Genius 8¢、Super Genius（2K）25¢。顔をきれいに保つ編集の見本は Super Genius
  → 品質を求めると **Gemini を直接使う（約5円）より高い**（Genius で約12円、Super Genius で約37円）
- **プライバシーが致命的**（プライバシーポリシー 2026年4月18日版）:
  - 利用者の情報を「自社の AI モデルの学習に使う」（ウェブの設定画面から拒否はできる）
  - 「AI モデルの学習などのために、第三者に情報をライセンスすることがある」
  - 「識別子と**利用者のコンテンツ（User Content）を第三者に販売する**」（18歳未満と分かっている人の情報は除く）
  - 利用規約でも、入力と出力を「サービスの開発・改善」に使えるとしている
- 年齢: 18歳未満は親の監督のもとでのみ利用可
- **判断: 使わない。** 利用者の自撮りを送る先として、学習・第三者への販売がありうる会社は、プライバシーポリシーに書けず、
  GDPR や App Store の審査（外部 AI への個人データの送信の明示と同意）にも耐えられない。中身のモデルも分からず、本人らしさも検証しにくい

**中継・まとめ役のサービスを選ぶときの確認点（DeepAI・fal.ai・Replicate などに共通）**
1. 中身のモデルとその提供元が分かるか（提供元の規約も一緒にかかる）
2. 送った写真を学習に使わない・第三者に渡さない、と契約で約束しているか（データ処理の契約があるか）
3. エンドユーザーの年齢の条件
4. 直接使うより安いか（多くは上乗せがある）

## 11. Meta「Muse Image」（Meta Model API）（2026-11-04 確認）

- 2026年8月26日から開発者向け API（Meta Model API、`dev.meta.ai`）で使える。モデル名 `muse-image-1.0`
- **1枚 $0.01（約1.5円）**。Gemini（Nano Banana 2.1、約5円）の約3分の1
- 文章からの生成・**写真の編集**・複数の写真の合成が1つのモデルでできる。API の形は OpenAI の Images API と同じ
  （`/v1/images/edits`）なので、OpenAI 用のコードの接続先を変えるだけで呼べる
- 「考えてから描く」型のモデル。そのぶん**遅め**: OpenRouter の計測で待ち時間の中央値 約17秒（Gemini は数秒）
- 人の好みの投票（Arena）: 単一画像の編集で2位（1,405、1位の GPT Image 2 は 1,466）という時期があり、2026年9月のまとめでは4位（1,306）。
  順位は変動している
- 本人らしさの公開データは無い。**「日本人の顔を参考画像から編集すると本人らしさが保てなかった」という報告が1件**ある（再現性は不明）→ 要検証
- **規約（Meta Model API 利用規約、2026年10月9日版、原文確認）**
  - 「あなたとエンドユーザーは18歳以上でなければならない。18歳未満向けのアプリを作ってはいけない」→ MARUMIE AI PHOTO（18歳以上）なら問題なし
  - Muse Image は「Standard（標準）」のモデル → **送った写真を Meta のモデルの学習に使わない**。Meta はデータ処理の受託者として扱う
    （別区分の「Contributor」モデルは学習に使われるので、選ばないこと）
  - 違反の検出・安全のために、内容を保持・処理することはある
  - 使えない地域: Muse Image はインド（とロシアの制裁対象地域など）。日本・米国・EU は対象外
  - 別のサービスを経由した再販は禁止（Meta が認めた提供先は可）
  - 利用者の顔などの生体情報の法律（イリノイ州など）を守る責任は開発者側
- **判断: Gemini と並ぶ有力候補。** 費用が3分の1になるのは大きい（無料枠を広げられる）。
  弱点は待ち時間（約17秒）と、日本人の顔での本人らしさが未知数な点。検証で Gemini と直接比べる
